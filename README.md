# Portfólio — Rafael Porto

Portfólio pessoal criado para apresentar minha trajetória, habilidades e projetos em desenvolvimento web.

## Sobre o projeto

Uma experiência moderna e responsiva, com identidade visual minimalista, alternância entre temas claro e escuro e um fundo interativo que acompanha a navegação.

O portfólio reúne:

- Apresentação profissional
- Habilidades e tecnologias
- Projetos selecionados
- Currículo para download
- Formas de contato

## Tecnologias

- React
- TypeScript
- Vite
- CSS
